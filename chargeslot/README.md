# ChargeSlot

**ChargeSlot — EV Charging Station Finder with Slot Dashboard and Auto-Booking System**

ChargeSlot is a modular, multi-tier electric vehicle charging and slot reservation platform developed for PES University Software Engineering.

### Core Modules & Sprints
- **Sprint 1 (F1):** User Identity, Authentication, and Access Control (RBAC)
- **Sprint 2 (F1 & F2):** User Profile, Vehicle Profile, and Station Onboarding
- **Sprint 3 (F2):** Station Discovery, Real-time Connector Dashboard, Navigation
- **Sprint 4 (F3):** Battery-Aware Booking and Auto-Booking Engine
  - **CS19-055 / REQ-F3-01:** Vehicle Battery Level Input & Usable Range Estimation
- **Sprint 5 (F3):** Charging Sessions, Check-in, and Simulator
- **Sprint 6 (F4):** Payments, Settlement, and Analytics

For backend documentation, refer to [chargeslot/backend/README.md](backend/README.md).
